# Budget Categories

This page helps you choose the correct **Budget Line** (expense account code) when entering expenses in Zoho. These codes follow the 2026-2027 budget template. If no code is a clear fit, confirm with the Financial Officer before using an "Other Expenses" line.

{: .important }
> Use the active 2026-2027 codes below for new expenses. Several prior-year codes were renumbered or deactivated in the updated budget template.

## Compensation & Staff Support

| Code | Account Name | Usage |
|------|--------------|-------|
| `700` | `Employee Salaries (FT)` | Full-time employee salary costs. |
| `701` | `Employee Salaries (PT)` | Part-time employee salary costs. |
| `702` | `Employee Salaries (WL)` | Work-learn or wage-subsidy employee salary costs. |
| `703` | `Employee Benefits (FT)` | Benefits and related employer costs for full-time employees. |
| `704` | `Employee Benefits (PT)` | Benefits and related employer costs for part-time employees. |
| `705` | `Professional Development – Staff` | Training and professional development for staff. |
| `706` | `Staff Appreciation` | Staff appreciation and recognition costs. |
| `707` | `Executive Honoraria` | Executive compensation paid as honoraria. |
| `708` | `Council Honoraria` | Approved honoraria for Council roles. |
| `709` | `Professional Development – Council, Committee and Executives` | Training and professional development for Council, committee members, and executives. |
| `710` | `PT Staff Costs – Programs` | Part-time staffing for program delivery. |
| `711` | `PT Staff Costs – Events` | Part-time staffing for event delivery. |
| `712` | `PT Staff Costs – Orientation` | Part-time staffing for orientation activities. |
| `713` | `PT Staff Costs – Commercial Events` | Part-time staffing directly supporting commercial events. |
| `714` | `PT Staff Costs – AO Subsidies` | Part-time staffing for affiliated organization subsidy work. |
| `715` | `PT Staff Costs – Grad Events` | Part-time staffing for graduate events. |
| `716` | `PT Staff Costs – Other Operating` | Other operating part-time staffing costs that do not fit a more specific staff line. |

## Other / Residual

| Code | Account Name | Usage |
|------|--------------|-------|
| `799` | `Other Expenses – Operating` | Operating expenses only when no specific operating budget line applies. |
| `899` | `Other Expenses – Restricted` | Restricted expenses only when no specific restricted budget line applies. |

{: .note }
> If an expense could fit a specific code, use that specific code instead of `799` or `899`.
